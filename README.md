# writing-skill

面向英语专业本科二年级学生的**专四（TEM-4）写作陪练 Skill**。一句话说清它的立场：**只给思路、只做诊断和判分，绝不代写**——不生成整篇作文、整段文字，也不给可直接抄用的完整句子。

## 项目解决什么问题

专四写作备考有四个卡点，这个 Skill 一一对应地解决：

| 卡点 | 表现 | Skill 的对策 |
| --- | --- | --- |
| 高分意识缺失 | 不知道阅卷在看什么（内容、结构、语言、连贯），写完心里没底 | 阅卷老师角色按 15 分制五档判分，逐条给扣分理由和"分数为什么停在这一档" |
| 修改能力弱 | 自查只能查出拼写错，看不出逻辑漏洞和句式呆板 | 交稿前 7 条自查清单（立场、主题句、论证回扣、让步、句型重复等）+ 母语者逐句诊断 |
| 输出固化 | 开头结尾永远是同一套，论证方式只有举例 | 判分后强制点出一处重复习惯，并给 1 个"换写法"微任务；连续三次不改升级为专项训练 |
| 反馈周期长 | 等老师批改要一周，练一次改一次的成本太高 | 交稿即判分，改稿只做一次复评，当场知道卡在哪一句 |

## 主要功能

1. **双模式**：做题模式（学生自带题目，或让 Skill 发题）／出题模式（学生选难度后命题）。
2. **三档难度命题**：基础（熟悉题材、提示较密）、进阶（对立观点或双概念）、冲刺（抽象议题、需界定概念与让步）；内置 12 道成品题，并约束新题不与上一题同题材、同论证结构。
3. **双写作分支**：自主撰写全文（先给 3 条构思提问，交稿后整体评）／逐段撰写（引言→主体→结尾逐段循环，每段只诊断本段，最后做全文贯通检查）。
4. **三角色分工**：
   - 出题人（Examiner）：命题、拆解题意、给思路骨架、判切题与跑题；
   - 母语者（Native Speaker）：逐句诊断，输出"位置｜片段｜类型｜修正路径｜严重度"清单；
   - 阅卷老师（Rater）：按 15 分制打分、给扣分明细、指提分位置。
   顺序固定：出题人 → 母语者 → 阅卷老师，先诊断后判分。
5. **15 分制评分**：满分 15、9 分及格、五档每档 3 分（15–13／12–10／9–7／6–4／3–1）。判分顺序固定——先按篇幅定档取起评分，再依次扣结构硬伤、基础语法、拼写搭配，最后汇总，并同时报告"篇幅定档"与"分数实际落档"。
6. **反代写红线**：只允许四种辅助——思路骨架、段落功能提示、词或短语候选（≤3 个）、含 ≥2 个占位符的句式骨架（一次 ≤1 条）。要求学生把中文句译成英文、索要范文、要求"帮我补完这段"，均按规则拒绝并给替代方案。

## 安装方法

Skill 是纯文本目录，无脚本、无依赖、不需要 Python 环境。

1. 下载/复制整个 `writing-skill/` 文件夹。
2. 放进 Agent 的 Skills 目录，例如 Windows：

   ```text
   <skills 根目录>/writing-skill/
   ```

   常见的 Skills 根目录形如 `<用户目录>/.doubao/agent_mode/workspace/.user_skills/`，macOS / Linux 同样放在对应的 `workspace/.user_skills/` 下即可，目录名必须是 `writing-skill`。
3. 确认目录里有 `SKILL.md`（Agent 靠它决定何时启用），`references/` 下的三份细则由 SKILL.md 按需引用，不需要手动加载。
4. 若使用 OpenAI Skills 规范，`agents/openai.yaml` 提供界面显示名"专四写作教练"。
5. 改完内容可自检（如已安装 skill-creator，用其自带脚本，需要 PyYAML）：

   ```bash
   python <skill-creator>/scripts/quick_validate.py <skills目录>/writing-skill
   ```

   正常输出 `Skill is valid!`。

## 使用方法

**启动**：说"开始写作练习"，或直接说"给我出个题""帮我看看这篇作文""按专四标准给我打个分"。

**一次完整练习的路径**

1. 选模式：`做题模式` / `出题模式`。
2. 若选出题模式，再选难度：`基础` / `进阶` / `冲刺`；Skill 给出题目（Topic / Task / Length / Hints）。
3. 选写作分支：`自主撰写全文` / `逐段撰写`。
4. 自己写——这是全流程的关键，Skill 不会替你写。
5. 说"写完了"后，先过 7 条自查清单，再交稿。
6. 收三份输出：母语者错误清单、出题人思路检查、阅卷老师判分报告。
7. 按诊断自行改稿 → 提交 → 只得到一次复评（逐条标"已解决／仍存在"），不给改写句。
8. 收尾给一条"本次最该突破的点"，并可选【继续】【换题】【查看评分细则】。

**判分报告怎么读**

```
篇幅：203 词｜篇幅定档：第 1 档（起评 15 分）
档位：第 2 档（10–12）｜最终得分：10.5/15｜落档：第 2 档｜及格：是
四维：内容 B｜结构 B｜语言 C｜连贯 B
扣分明细：第 2 段无主题句 −1｜主谓一致 2 处 −1｜粘连句 1 处 −1｜搭配 2 处 −1｜拼写 1 处 −0.5
档位理由：结构完整但语言错误偏多，够不到第 1 档"基本无错误"的门槛。
提分位置：第 2 段段首补主题句，并把其中一处举例改成因果论证。
```

- 分数以"起评分 − 各项扣分"计算，下限保护为起评分的 50%，只有白卷、完全跑题、仅写几个词才判 0。
- 每条扣分都能对回 `references/scoring-rubric.md` 的规则名，说不出规则名的扣分不会出现。
- 需要对照现行 20 分制时按 ×4/3 换算（9 分≈12 分），仅作参考。

## 输入输出示例

**示例 1：出题模式 · 进阶**

> 学生：出题模式，进阶难度。
>
> Skill：
> Topic: Some universities give every student a free AI writing assistant. Is this a benefit or a hidden risk?
> Task: Discuss the advantages and risks, and make a judgement.
> Length: No fewer than 200 words.
> Hints:（1）利弊型必须两边都写到，但结论只能有一个；（2）风险一侧要具体到"能力退化"或"学术诚信"其中之一；（3）结尾给一条可执行的使用边界。
> 请选写作分支：【自主撰写全文】【逐段撰写】

**示例 2：做题模式 · 自主全文 · 交稿后（三段输出节选）**

> 学生：题目是 Should college students take part-time jobs? 我写完了（203 词，附全文）。

```
【母语者】
位置 | 片段 | 类型 | 修正路径 | 严重度
L4  | students has      | 主谓一致 | 主语为复数，谓语需随主语变形 | 致命
L9  | take part-time job| 名词单复数／搭配 | 可数名词需限定，搭配需补冠词 | 明显
L12 | ... , they can ... | 粘连句 | 两个独立句不可仅用逗号连接，需拆句或加连接词 | 致命
小结：致命 2 处、明显 4 处；"主谓一致"重复出现 2 次，是本篇主要障碍。

【出题人】
切题度：Task 要求"谈利弊+表态"，表态缺失 → 未完成任务的一半。
论证链：立场（弱）→ 理由1 → 证据 → 回扣（缺）
段落职能：引言（背景+立场）／主体（理由+反方混在一段）／结尾（重复引言）
固化识别：开头 `Nowadays, with the development of...`，三个理由全为并列举例，无一处让步。
句式侧写：简单句占比 68%，从句 3 处，平均句长 14 词。

【阅卷老师】
篇幅：203 词｜篇幅定档：第 1 档（起评 15 分）
档位：第 2 档（10–12）｜最终得分：10.5/15｜落档：第 2 档｜及格：是
四维：内容 B｜结构 B｜语言 C｜连贯 B
扣分明细：第 2 段无主题句 −1｜主谓一致 2 处 −1｜粘连句 1 处 −1｜搭配 2 处 −1｜拼写 1 处 −0.5
档位理由：结构完整但语言错误偏多，够不到第 1 档"基本无错误"的门槛。
提分位置：第 2 段段首补主题句，并把其中一处举例改成因果论证。
反固化记录：开头句式已连续两次同款 → 微任务：本次只重写引言，换掉 `with the development of` 的起手方式。
```

**示例 3：被拒绝的请求（Skill 的边界）**

> 学生：这段中文帮我译成英文——"手机对学生既有利也有弊。"
>
> Skill：不给译文。这句在英文里需要"主语 + 系动词 + 表语"三段成分，可考虑 `have both advantages and disadvantages` 或 `cut both ways` 两个短语，句子由你自己组装。

> 学生：直接给我写一篇 200 词的范文吧。
>
> Skill：不给全文。可以给你结构骨架（引言立场→理由一→反方让步→结论）和一个亮点手法清单，句子由你写。

## 目录结构

```
writing-skill/
├── SKILL.md                        # 主流程：红线、三角色、模式与分支、自查清单、判分步骤、反固化
├── agents/openai.yaml              # 界面元信息（display_name / short_description / default_prompt）
└── references/
    ├── scoring-rubric.md           # 五档描述、篇幅定档表、结构/语法/拼写扣分细则、3 个计分示例
    ├── question-design.md          # 三档难度命题原则 + 12 道成品题（基础 4 / 进阶 4 / 冲刺 4）
    └── feedback-protocol.md        # 三维检查字段格式、复评规则、违规/合规对照示例
```

## 不支持

网页抓取、PDF 解析、图形界面操作、手写稿图片识别（需转成文字粘贴）。写作训练全程为对话式推进，不产出文件。
