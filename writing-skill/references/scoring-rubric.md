# 专四写作评分细则（15 分制）

本文件是 `writing-skill` 判分的唯一依据。阅卷老师角色每次判分都必须按此处的档位、扣分项和计算方式执行，不得自行加严或放宽。

## 目录

1. 评分基准
2. 五档描述
3. 篇幅定档表
4. 结构硬伤扣分
5. 语言扣分（语法、拼写、搭配）
6. 严重度与封顶规则
7. 汇总与落档

## 1. 评分基准

- 满分 15 分，**9 分及格**，五档、每档 3 分：15–13 / 12–10 / 9–7 / 6–4 / 3–1。
- 判分顺序固定：**篇幅定档 → 结构硬伤 → 基础语法 → 拼写搭配 → 汇总落档**。
- 专四作文按错误点数扣分，不采用整体印象加分（与四六级不同），因此每一分都要能指到具体句子。
- 现行考纲对作文的基本要求：不少于 200 词、45 分钟、内容相关、概括全面、理据充分、语法正确、用词恰当、表达得体。练习场景按同一口径执行。

## 2. 五档描述

| 档位 | 分数 | 描述 |
| --- | --- | --- |
| 第 1 档 | 13–15 | 切题，思想表达清楚，文字通顺，连贯性好，基本无语言错误，且有语言亮点（句型或论证有可取之处） |
| 第 2 档 | 10–12 | 切题，思想表达清楚，文字连贯，有少量语言错误，无致命错误 |
| 第 3 档 | 7–9 | 基本切题，表达基本清楚，连贯性尚可，语言错误较多，其中少量较严重 |
| 第 4 档 | 4–6 | 基本切题，表达不够清楚，连贯性差，语言错误多且较严重 |
| 第 5 档 | 1–3 | 条理不清，思路紊乱，语言支离破碎，多数句子有严重错误 |

0 分：白卷、与题目毫不相干、只写几个单词、通篇照抄提示语。

**及格判定**：≥ 9 分。落在第 3 档上限（9）即为"勉强及格"，需要零结构硬伤支撑；有任一硬伤通常掉到 8 分以下。

## 3. 篇幅定档表

先数字数（不含照抄提示的句子），按累计字数落档，取该档上限作为**起评分**：

| 累计字数 | 定档 | 起评分 |
| --- | --- | --- |
| ≥ 200 | 第 1 档（13–15） | 15 |
| 180–199 | 第 2 档（10–12） | 12 |
| 160–179 | 第 3 档（7–9） | 9 |
| 140–159 | 第 4 档（4–6） | 6 |
| < 140 | 第 5 档（1–3） | 3 |
| 白卷／完全跑题／仅几个词 | 0 分 | 0 |

多写不扣分，但头重尾轻、明显没写完按"缺结尾段"处理（见第 4 节）。照抄题目或提示中的原句不计入字数，且需在诊断中标注。

## 4. 结构硬伤扣分

| 硬伤 | 扣分 | 判定标准 |
| --- | --- | --- |
| 跑题／未回应任务 | −5，且总分不得 ≥ 9 | 主体内容与题目要求无关，或答非所问（如要求讨论利弊却只讲做法） |
| 缺结尾段 | −3 | 全文在主体段后直接结束，无收束 |
| 无明确立场 | −2 | 通篇罗列双方观点，始终不表态，或表态与前文矛盾 |
| 主体段无主题句 | −1／段，最多 −2 | 段落开头没有概括本段中心的句子 |
| 一段多中心／段序混乱 | −1 | 段内出现两个以上互不相关的论点，或论证顺序倒置 |
| 论证断裂 | −1 | 论据与论点无关，或例证后不作回扣 |
| 段间无衔接 | −1 | 连续两段之间无任何衔接手段，读者需自行推断关系 |
| 全文重复同一论点 | −1 | 两段论证实为同一内容，凑字数 |

结构硬伤合计最多扣 8 分。抄提示原句不扣分，但要在诊断中单列一行标注"抄袭提示，已排除字数统计"。

## 5. 语言扣分

**基础语法**（按处计，同类重复最多计 3 处）：

| 类型 | 每处 | 说明 |
| --- | --- | --- |
| 粘连句（comma splice / run-on） | −1 | 两个独立句仅用逗号连接，或两个谓语并列无连接 |
| 句子残缺（缺主语或谓语） | −1 | 从句当独立句使用 |
| 主谓一致 | −0.5 | 主语与谓语数不一致 |
| 时态误用／时态跳转 | −0.5 | 同一段落内无理由地换时态 |
| 冠词缺失或误用 | −0.5 | 可数名词单数前无冠词等 |
| 名词单复数 | −0.5 | 可数名词裸用、复数漏 s |
| 代词指代不清 | −0.5 | 指代对象不唯一 |
| 平行结构不齐 | −0.5 | and / or 前后词性不一致 |
| 语态、非谓语误用 | −0.5 | 分词悬垂、被动误用 |

语法扣分合计封顶 −4。

**拼写**：每处 −0.5，合计封顶 −1.5。
**搭配与用词**：每处 −0.5，合计封顶 −2（含中式搭配如 `learn knowledge`、`pay attention on`、词性误用、正式文体中混入口语表达）。

## 6. 严重度与封顶规则

- **致命**：导致意思读不懂（粘连句、残缺句、主谓一致造成歧义）。必须逐条列出，且不因"看得懂大意"而免扣。
- **明显**：影响流畅但不影响理解（时态、冠词、单复数、搭配）。
- **轻微**：不地道但可读（选词偏口语、冗余表达）。轻微错误不扣分，但要进诊断清单，3 处折算 −0.5。
- 同一错误反复出现，按"同类最多计 3 处"封顶，避免一篇作文因同一毛病被判死。
- 三项扣分（结构、语法、拼写搭配）互不冲抵，各按各的表算。

## 7. 汇总与落档

```
最终得分 = 定档起评分 − 结构硬伤扣分 − 语法扣分 − 拼写搭配扣分
下限 = 定档起评分的 50%（四舍五入到 0.5）
```

**下限保护**：即使扣分累计超过起评分，最终分也不跌破起评分的一半，只有白卷、完全跑题、仅写几个词三种情形直接判 0。理由是篇幅本身已经把上限压低，再叠加语言扣分必然压到 0，反馈就失去颗粒度，学生也看不出到底卡在哪。

输出时必须同时给出两个信息：

1. **篇幅定档**（第 X 档，起评 X 分）；
2. **分数实际落档**（最终分所在区间）。

两者相差两档及以上时，用一句话说明原因，例如"语言错误过多，实际水平低于篇幅档"。

改稿后重新判分时，若字数跨越了定档区间（如从 155 词补写到 205 词），必须重新定档、重新起评，不能只在原分数上加分。

## 8. 四维评分表

四维只用于描述强弱点，不另外加分，避免出现两套分数：

| 维度 | 评级 | 依据 |
| --- | --- | --- |
| 内容 | A／B／C／D | 是否切题、论点是否明确、论据是否具体 |
| 结构 | A／B／C／D | 分段、主题句、段序、结尾 |
| 语言 | A／B／C／D | 语法扣分数量与严重度、句式多样性 |
| 连贯 | A／B／C／D | 衔接手段、指代、重复 |

评级映射：A = 第 1 档水平，B = 第 2 档，C = 第 3 档，D = 第 4–5 档。每个维度后附一句可核对的具体证据（指向段号或句号）。

## 9. 计分示例

### 示例 A（篇幅达标，语言偏弱）

> 题目：Should college students be allowed to use AI tools in their writing assignments?
> 字数：约 205 词（≥200，第 1 档，起评 15）

核查结果：

| 项目 | 细节 | 扣分 |
| --- | --- | --- |
| 结构 | 主体段一开头直接举例，无主题句；三个主体段全部使用举例论证 | −1（无主题句） |
| 结构 | 结尾段仅重复第一段，无收束或建议 | −1（重复同一论点） |
| 语法 | 主谓一致 2 处（`students has`、`people thinks`） | −1 |
| 语法 | 粘连句 1 处（两个完整句用逗号相连） | −1 |
| 语法 | 时态跳转 1 处（同一段内过去时与现在时混用） | −0.5 |
| 拼写搭配 | 搭配 2 处（`learn knowledge`、`pay attention on`） | −1 |
| 拼写搭配 | 拼写 1 处（`enviroment`） | −0.5 |

计算：15 − 1 − 1 − 1 − 1 − 0.5 − 1 − 0.5 = **9 / 15**

输出：篇幅定档第 1 档，分数落第 3 档上限，及格（勉强）。提分位置：给主体段一补主题句、换掉一段举例论证为因果论证，即可回到第 2 档。

### 示例 B（篇幅不足，硬伤明显）

> 题目同上。字数：约 155 词（落在 140–159 区间 → 第 4 档，起评 6）

核查结果：

| 项目 | 细节 | 扣分 |
| --- | --- | --- |
| 篇幅 | 155 词，未达 200 词最低要求 | 已定档第 4 档（不再重复扣分） |
| 结构 | 无结尾段，第二段举例后直接结束 | −3 |
| 结构 | 通篇讲"AI 很方便"，未回应"是否应该允许" | −2（无明确立场） |
| 语法 | 主谓一致 2 处 | −1 |
| 语法 | 残缺句 1 处 | −1 |
| 拼写搭配 | 拼写 1 处、搭配 1 处 | −1 |

计算：6 − 3 − 2 − 1 − 1 − 1 = −2，触发下限保护（6 的 50% = 3）→ **3 / 15**

这里需要解释下限：篇幅本身已把上限压到 6 分，再扣结构硬伤即接近 0。档位说明写"篇幅不足叠加结构硬伤，卡在第 5 档区间"，并给出最省力的补救顺序：先补结尾段，再补立场句，最后才是语言错误。低档位的反馈重点永远是**篇幅与结构**，不是逐条数语法错。

### 示例 C（扣分封顶演示）

> 一篇 210 词的作文，语法错误 12 处（含 4 处主谓一致、3 处冠词、2 处时态、3 处单复数），拼写 5 处。

计算：语法按表算为 −0.5×9 = −4.5，触发封顶 −4；拼写 −2.5，触发封顶 −1.5。若结构无硬伤，15 − 4 − 1.5 = **9.5**，四舍五入到 0.5 后取 **9.5/15**（落在第 3 档，及格）。封顶的作用就是防止语言错误把一篇结构完整的作文压到不及格。

## 10. 依据说明

- 五档划分、9 分及格、12 分优秀、按错误点扣分、跑题重扣、缺结尾段扣 3 分、"多写不扣分、过分简略降档"等规则，来自专四作文阅卷标准与传统 15 分制的通行口径（见《解读英语专四作文阅卷标准》等公开讲评材料）。
- 现行 TEM-4 写作部分为 20 分、45 分钟、不少于 200 词；本 Skill 沿用 15 分制换算练习口径，篇幅要求按"不少于 200 词"锁定，便于与真实考纲对齐。
- 本表的扣分颗粒度（0.5 分、封顶值、字数控档）是为训练场景做的细化，判分时以"可解释、可核对"为第一原则。
