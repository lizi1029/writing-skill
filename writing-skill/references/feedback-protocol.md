# 三维检查反馈协议

本文件规定【母语者】【出题人】【阅卷老师】三份输出的字段、写法与禁止项。三维检查指：**语法层、思路层、阅卷层**。

## 目录

1. 通用纪律
2. 第一维：母语者／语法层
3. 第二维：出题人／思路与结构层
4. 第三维：阅卷老师／判分层
5. 修订回合的复评
6. 允许与禁止对照示例
7. 一页式输出模板

## 1. 通用纪律

- 三份输出**分节呈现、顺序固定**，先语法、再思路、最后判分。不得先报分数再找错误。
- 每一条结论都要定位到具体句子（用 `L1` 或"第 2 段第 3 句"编号），便于学生自己动手改。
- 只诊断、不代改：**不给改写后的句子、不给整段润色、不给"这样写更好"的成品**。
- 一次最多指出 8 条问题，按严重度排序；轻微问题最多 3 条，避免淹没重点。
- 学生没写的部分，不预测、不替写。

## 2. 第一维：母语者／语法层

输出一张表，字段固定：

| 位置 | 片段（原样引用） | 类型 | 修正路径 | 严重度 |
| --- | --- | --- | --- | --- |

写法要求：

- **类型**取自 scoring-rubric.md 第 5 节的分类名（主谓一致、时态、冠词、单复数、残缺句、粘连句、搭配、拼写、指代、平行结构、语态）。
- **修正路径**只写"要动什么"，不写"改成什么"。合格写法示例：`主语为复数，谓语需随主语变形`、`可数名词单数前需限定`、`两个独立句不可仅用逗号连接，需拆句或加连接词`。
- **严重度**用三档：致命（影响理解）／明显（影响流畅）／轻微（不地道）。致命项必须置顶。
- 表后加两行小结：致命 X 处、明显 Y 处、轻微 Z 处；并指出**重复性毛病**（同一类型出现 3 次以上者），这类毛病是提分的主要障碍。
- 需要给词汇时，只给词或短语候选，最多 3 个，格式 `word / phrase / collocation`，并标注词性。不得给含主谓的完整表达。

## 3. 第二维：出题人／思路与结构层

不评语言，只查四件事，每件一行结论 + 一行证据：

1. **切题度**：是否回应了 Task 的全部要求（列出要求的动作，逐条打勾或划叉）。漏掉任何一个动作即记为"未完成任务"。
2. **论证链闭合**：画一条文字链条 `立场 → 理由1 → 证据 → 回扣`，缺哪一环就标出来。回扣缺失是最常见的隐性扣分点。
3. **段落职能**：逐段标职能（背景／立场／理由／反方／让步／结论），并指出职能重复或缺失的段落。
4. **固化识别**：检查是否出现以下模板化痕迹——开头永远是 `Nowadays, with the development of...`；结尾永远是 `In conclusion, we should...`；三个理由全是并列举例；全文没有一处让步或条件限定。命中即写入"反固化"记录。

句式侧写（用于判断是否"句式呆板"）：统计简单句占比、从句数量、平均句长、是否出现非谓语或插入语。只报数据 + 一句判断，不示范写法。

## 4. 第三维：阅卷老师／判分层

按以下字段输出，顺序不可调换：

```
篇幅：___ 词｜篇幅定档：第 X 档（起评 X 分）
档位：第 X 档（X–X）｜最终得分：X/15｜落档：第 X 档｜及格：是/否
四维：内容 X｜结构 X｜语言 X｜连贯 X（每项附一句证据）
扣分明细：（逐条：位置 — 规则 — 分值）
档位理由：两句以内，说明为什么是这个档而不是上一档或下一档
提分位置：本次只改一处，指出段号与要完成的动作
反固化记录：一处重复习惯 + 1 个换写法微任务
```

硬性要求：

- 扣分明细**每一行都要有位置和规则名**，能与 scoring-rubric.md 对应上；说不出规则名的扣分不许写。
- 0.5 分为最小单位，不出现 0.25 或"酌情"。
- 不允许"整体感觉不错，给 11 分"这类无法核对的表述。
- 若学生本次分数高于上次同一维度，明确写出"因何提升"；若持平或下降，写出卡点，不做安慰。

## 5. 修订回合的复评

学生自行改稿后，只输出一张对照表：

| 原问题（位置+类型） | 状态 | 说明 |
| --- | --- | --- |
| L1 主谓一致 | 已解决 | 谓语已随主语变形 |
| L2 名词单复数 | 仍存在 | 名词仍为单数裸用 |

复评允许做的事：确认是否解决、指出新引入的错误、更新分数（只更新分数与档位，不重写全套诊断）。
复评禁止做的事：提供正确句子、整段示范、把学生没改到的地方"顺手补好"。

## 6. 允许与禁止对照示例

| 场景 | ❌ 违规（等于代写） | ✅ 合规 |
| --- | --- | --- |
| 学生卡在开头 | "可以这样开头：Nowadays, part-time jobs have become increasingly popular among college students." | "开头需要完成'现象—争议—立场'三件事，你目前只写了现象。先想一句能概括争议的短语。" |
| 句子太短、全是简单句 | "把这两句合并成：Although part-time jobs take up much time, they help students learn to manage it." | "第 3、4 句都是简单句，语义上是从属关系。可考虑一条让步骨架：`Although ___, ___ still ___.`（一次只给这一条）" |
| 学生要范文 | "给你一篇 200 词的范文参考。" | "不给全文。可以给你这篇的结构骨架（引言立场→理由一→反方让步→结论）和一个亮点手法清单，句子由你写。" |
| 段落没写完 | "这段我帮你补完，你抄一下。" | "这段缺回扣句，缺的那一句需要你自己写。先回答：你这条理由想证明立场中的哪一半？" |
| 逐段模式 | "第一段我已经替你写好了，你接着写。" | "先给第一段的功能提示（背景+立场，不超过三句），你写完发我。" |

## 7. 一页式输出模板

```
【母语者】错误清单
（表格 5 列）＋ 一行小结＋ 重复性毛病标记

【出题人】思路检查
切题度：…
论证链：立场 → 理由 → 证据 → 回扣（缺：…）
段落职能：…
固化识别：…
句式侧写：简单句占比 __%，从句 __ 处，平均句长 __ 词

【阅卷老师】判分
（按第 4 节字段顺序输出）
```
